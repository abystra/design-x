## 手工验收清单

- [ ] 首页与 AI 工作区在 1440、1024、390 px 宽度下没有横向溢出。
- [ ] 开始创作直接进入工作区，技能面板默认打开。
- [ ] 技能 / 文件 / 记录 / 资产面板切换不丢输入，`/` 与 `@` 正常打开对应入口。
- [ ] 首页文字与附件带入；3 个方案生成后可选中、拖动标题、平移与缩放。
- [ ] 点击继续修改，新比例 / 新素材 / 新文案应用到新版本并保留原稿。
- [ ] 取消或刷新后重试，仍使用原需求和素材；重复重试无重复结果 ID。
- [ ] 精细编辑修改图层，返回后预览更新且原对话仍保留。
- [ ] 存储超额有反馈；刷新 `#studio` 能恢复当前会话。
- [ ] 空白需求提交有提示，示例需求可以带到正确的任务类型。
- [ ] 商品套图使用示例后，调整数量、比例和风格，结果符合摘要。
- [ ] 演示失败能重试，运行能取消，已有配置保留。
- [ ] 模板进入编辑器，修改文案、拖动图层、撤销和重做。
- [ ] 保存作品后重新打开，恢复修改后的文字与位置。
- [ ] PNG、JPG、SVG 可下载，导出尺寸与倍率相符。
- [ ] 新建文件夹、重命名与移入文件夹，刷新后仍保留。
- [ ] 上传、收藏和品牌色卡保存；错误文件与容量限制有反馈。
- [ ] 搜索无结果时可以恢复到完整目录。
